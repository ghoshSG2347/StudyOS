# Official documentation consulted

- Convex + Better Auth Getting Started: https://labs.convex.dev/better-auth
- Convex + Better Auth React Vite guide: https://labs.convex.dev/better-auth/framework-guides/react
- Better Auth Convex integration: https://better-auth.com/docs/integrations/convex
- Better Auth Google provider: https://better-auth.com/docs/authentication/google
- Better Auth email/password and reset: https://better-auth.com/docs/authentication/email-password

The React Vite guide documents Convex 1.25.0 or newer and Better Auth `~1.6.15` at research time, and specifies `@convex-dev/better-auth`, `ConvexBetterAuthProvider`, `crossDomain`/`convex` plugins, and OAuth callback on the Convex `.convex.site` domain. Re-check these sources when installing or deploying because compatibility and API details can change.
